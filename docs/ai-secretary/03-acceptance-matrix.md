## 关键流程验收脚本

### E2E-01：语音任务闭环

1. 打开秘书页。
2. 模拟输入：“明天下午三点提醒我给房东打电话，半小时”。
3. 检查任务草案包含标题、时间、时长。
4. 点击确认。
5. 检查任务进入今日/明日计划。
6. 点击完成。
7. 检查任务状态为已完成且没有待处理提醒。

### E2E-02：冲突重排

1. 固定日历事件占用 14:00—15:00。
2. 新增 60 分钟弹性任务，截止 18:00。
3. 生成计划。
4. 检查候选时间不落在 14:00—15:00。
5. 检查预览展示任务安排位置。
6. 确认计划。

### E2E-03：模型失败降级

1. 模拟模型超时或返回非法 JSON。
2. 输入原始文本。
3. 检查原始文本仍保存在 Inbox。
4. 检查用户看到明确错误和重试入口。
